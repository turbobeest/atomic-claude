ATOMIC CLAUDE Commands

Main Commands

./main.sh run <phase>
Run a specific phase (0-9)
./main.sh status
Show current pipeline status
./main.sh list
List all available phases
./main.sh reset
Reset entire pipeline state

Phase Flags

./main.sh run 1 --resume-at=107
Resume from specific task
./main.sh run 1 --redo
Force redo all tasks in phase
./main.sh run 1 --status
Show task state for current phase

Phase 0 Setup

./main.sh run 0 --task=005
Resume Phase 0 from specific task
./main.sh run 0 --skip-intro
Skip the intro animation

Dashboard

./scripts/start-dashboard.sh
Manually start tasks dashboard
cd tasks-dashboard && npm start
Start dashboard via npm
