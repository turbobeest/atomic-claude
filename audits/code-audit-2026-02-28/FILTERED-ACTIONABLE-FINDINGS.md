## Notes on Methodology

1. **CRITICAL threshold**: Required proof of runtime crash, data loss, data corruption, or security exploit on a normal code path. Of the 6 original CRITICALs, 3 were "no test coverage" (rejected -- not a code defect), 1 was "god function" (rejected -- code quality opinion). Only the 3 kept findings meet the strict criteria.
