▼ Run a Phase
python main.py run <phase>
Run a pipeline phase. Picks up where you left off if the phase was partially completed.
python main.py run 0 Setup
python main.py run 1 Discovery
python main.py run 2 PRD
▼ Resume from a Task
python main.py run <phase> --resume-at=<task>
Resume a phase from a specific task. Useful after fixing an issue or restarting a failed step.
python main.py run 0 --resume-at=004 Resume Setup at API keys
python main.py run 1 --resume-at=105 Resume Discovery at Opening dialogue
python main.py run 2 --resume-at=205 Resume PRD at Authoring
▼ Check Status
python main.py status
Show which phases are complete, which is active, and what comes next.
▼ Backtrack & Reset
python main.py backtrack <phase> [task]
Go back to an earlier phase. Clears all state, outputs, and memory after that point. Prompts for confirmation.
python main.py backtrack 1 Reset to Phase 1, clear Phase 2+
python main.py backtrack 0 005 Reset Phase 0 to Task 005
python main.py reset
Full reset — clears everything and starts fresh from Phase 0.
▼ Dashboard
bash dashboard/start-dashboard.sh
Start this dashboard and open it in the browser.
▼ Task Management (Graph)
python main.py task update <id> <prompt>
Update a task and show affected downstream tasks. Requires FalkorDB.
python main.py task update 5 "Change auth to OAuth2"
python main.py task research <id> <content>
Save research findings linked to a task in the knowledge graph.
python main.py task research 3 "JWT tokens expire after 1hr"
python main.py task add <title> <desc> [--depends-on ...] [--implements ...]
Add a new task mid-project. Optionally specify dependency and requirement links.
python main.py task add "Rate limiting" "Implement API rate limiting" -d 3 5
python main.py task complexity [--llm]
Analyze task complexity using graph topology. Use --llm to refine scores.
python main.py task complexity --llm
python main.py task validate
Validate the task dependency graph. Reports cycles and orphan tasks.
python main.py task fix
Auto-repair dependency graph issues (cycles and orphan tasks).
▼ Audit
python main.py audit run <audit_id>
Run a single audit by ID against the latest phase deliverables.
python main.py audit run security-trust.application-security.csrf-protection
python main.py audit run --phase <N>
Run all phase-appropriate audits (same as the pipeline audit gate).
python main.py audit run --phase 2 Run all PRD-applicable audits
python main.py audit run --phase 5 Implementation audits
python main.py audit run --category <name>
Run all audits in a specific category.
python main.py audit run --category security-trust
python main.py audit list [--phase <N>] [--category <name>]
List available audits. Optionally filter by phase applicability or category.
python main.py audit list --phase 5 Implementation audits
python main.py audit list --category code-quality
python main.py audit search <query>
Search audits by keyword match on ID, name, category, and subcategory.
python main.py audit search csrf
python main.py audit search authentication
python main.py audit results [--phase <N>]
Show the latest audit results. Defaults to most recent phase if --phase not specified.
python main.py audit results --phase 2 PRD audit results
▼ Phase Quick Reference
0 — Setup (config, API keys, environment)
1 — Discovery (materials, requirements gathering)
2 — PRD (product requirements document)
3 — Tasking (task decomposition, dependencies)
4 — Specification (OpenSpec, TDD setup)
5 — Implementation (TDD execution, code generation)
6 — Code Review (review, refinement)
7 — Integration (integration testing, approval)
8 — Deployment Prep (artifacts, deployment plan)
9 — Release (final release, changelog)
